# Study Time Tracker

This project is a simple Python program that helps users estimate their weekly study hours based on how much they studied today. 
It takes a single user input, performs a calculation, and displays the expected weekly total in a clear and friendly format.

# How to Run the Program

Make sure you have Python installed.
Then, in your terminal:
## python app.py
or on some systems:
## python3 app.py

# Example Interaction
Welcome to my Python program!
This program will help estimate your weekly study hours.

How many hours did you study today? 2

If you keep this pace, you will study about 14.0 hours this week!
